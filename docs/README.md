# PhysicalAI Documentation

PhysicalAI is the runtime package for loading exported robot policies, running inference, and executing policies on hardware.

Start with the [Documentation Home](index.md).

## Documentation Model

These docs follow the Diataxis structure.

- Tutorials live in `getting-started/`.
- Task guides live in `how-to/`.
- Conceptual material lives in `explanation/`.
- Exact lookup material lives in `reference/`.
- Detailed design history stays in `design/`.

The source format is plain Markdown. Site-specific MDX components are intentionally avoided until a docs site is selected.
